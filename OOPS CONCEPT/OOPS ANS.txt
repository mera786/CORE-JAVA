-> Aggregation : both objects can exist independently .
Real life ex-
A "Team" class that contains "Player" objects. Players can exist independently of the Team.
-> Composition : both objects can’t exist independently . one object can’t exist without owner object.
Real time ex -
A "Car" class that contains an "Engine" object. The Engine cannot exist without the Car.
